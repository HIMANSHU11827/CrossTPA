# 🌌 CrossTPA
**The Ultimate Cross-Platform Teleportation & Team Mastery Plugin**

CrossTPA is a high-performance, feature-rich Minecraft plugin designed specifically for hybrid servers. It bridges the gap between **Java** and **Bedrock** (via Floodgate), providing a seamless, secure, and highly interactive experience for all players.

---

## 💎 Core Features

### 🚀 Advanced Teleportation
*   **Java & Bedrock Optimized**: Native command support for Java and interactive **GUI Forms** for Bedrock.
*   **TPA / TPAHere / TPAAll**: Standard and mass teleportation requests.
*   **Safety Guards (Optional)**: Optional hazard prevention can be enabled to block teleports into Lava, Fire, Solid Blocks, or the Void (Disabled by default for maximum freedom).
*   **Movement Cancellation**: Optional setting to cancel teleport if the player moves.
*   **Admin Spy**: Staff can monitor all TP requests in real-time.

### 🛡️ Secure Economy (Anti-Counterfeit)
*   **Shard & Cluster Coins**: A unique NBT-based currency system.
*   **Mined-Amethyst Protection**: Prevents players from using regular mined amethyst pieces as "fake" money. Only plugin-generated coins are accepted.
*   **Physical Currency**: Withdraw your bank balance into physical coins or deposit them with a right-click.
*   **Currency Conversion**: Compress 4 Shard Coins into 1 Cluster Coin (and vice versa) with a simple click.

### 👥 Professional Team System
*   **Team HQ & Bases**: Set a team home or a strategic base for your squad.
*   **Flexible Ranks**: Leader, Co-Leader, Elder, and Member roles with granular permissions.
*   **Friendly Fire**: Toggle PvP within your team to prevent accidental hits.
*   **Team Alliances**: Forge powerful alliances with other teams.
*   **Team Chat**: Private communication channel for your members.

### 📜 Dynamic Missions & Bounties
*   **Automated Missions**: Track team-wide mob kills and objectives.
*   **Custom Creator Missions**: Leaders can create custom tasks (e.g., "Build a Fortress") and set manual rewards for members.
*   **Approval System**: Robust verification for custom tasks to ensure fair payouts.

### 🤝 Social & Security
*   **Friend System**: Add friends to bypass certain restrictions or see online status.
*   **Privacy Controls**: Toggle TPA requests, block annoying players, or mute specific users.
*   **Control Panel**: A visual `/tpamenu` to manage everything from one place.

---

## 🛠️ Configuration & Customization
CrossTPA is built for server owners. With over **30+ feature toggles**, you can enable or disable almost every aspect of the plugin (Bank, Teams, Missions, PvP, etc.) to fit your server's playstyle perfectly.
